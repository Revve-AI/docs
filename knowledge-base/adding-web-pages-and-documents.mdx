Your agent needs content to answer questions. This guide covers how to add web pages and documents to your knowledge base, and how to use website crawlers to automatically keep everything up to date.

## Adding Content on the Sources Page

Navigate to **Knowledge > Sources** in the left sidebar to access your team's central content library. From here, you can add individual web pages or upload documents.

![The global Knowledge Base showing a list of web page sources with their titles, URLs, types, statuses, and dates](/screenshots/knowledge-web-pages-docs.png)

### Adding a Web Page

1. Click the **Add** button in the top-right area of the Sources page.
2. Select **Add Web Page** from the dropdown menu. This opens the new crawler setup.
3. Enter the full URL of the page you want to add (for example, `https://yourcompany.com/pricing`) and choose **Single Page (Scrape)** as the indexing type.
4. Finish the remaining steps and submit. Revve will fetch the page content and index it.

See [Creating a New Crawler](#creating-a-new-crawler) for the full setup.

### Uploading a Document

1. Click the **Add** button.
2. Select **Upload Document** from the dropdown menu.
3. Drag and drop your documents, or choose files from your computer. You can upload several files at once and optionally add labels.
4. Click **Upload Documents**. The documents will be processed and added to your sources.

![The Add dropdown showing options to Add Web Page or Upload Document](/screenshots/knowledge-upload-document.png)

**Supported file formats:**

| Format | Description |
|---|---|
| PDF | Product guides, datasheets, policy documents |
| DOCX, DOC | Word documents, internal procedures. Tables in DOCX files keep their structure. |
| HTML, HTM | Saved web pages, exported help articles |
| MD | Markdown files, technical docs |
| TXT | Plain text files, notes, scripts |

## Making Content Available to an Agent

Agents don't use sources directly. To give an agent your content:

1. Add the sources to a knowledge base on the **Knowledge > Knowledge Bases** page.
2. Open your chat agent, go to the **Knowledge** tab, and click **Start Editing**.
3. On the **Knowledge Base** sub-tab, click **Attach Knowledge Base** and choose the knowledge base.
4. Publish the agent. Attaching a knowledge base is saved to the draft and only takes effect after publishing.

See [Knowledge Base Overview](/knowledge-base/knowledge-base-overview) for how sources, knowledge bases, and agents fit together.

![The Knowledge tab inside a chat agent in editing mode](/screenshots/knowledge-base-editing.png)

## Managing Knowledge Sources

Each source in your knowledge base has the following attributes:

| Column | Description |
|---|---|
| **Source** | The title and URL (for web pages) or filename (for documents). |
| **Type** | Either `WEB PAGE` or `DOCUMENT`. |
| **Labels** | Optional tags for organizing your sources. |
| **Status** | `Active` means the source is available to agents. You can deactivate a source without deleting it. |
| **Created At** | When the source was first added. |
| **Last Index** | When the content was last fetched and processed. |
| **Expiry At** | When the source expires, or "Never". See [Source Expiry](/knowledge-base/source-expiry). |
| **Action** | Deactivate, Activate, Re-index, or Retry indexing, depending on the source's status. |

### Filtering and Searching

Use the filters at the top of the sources table to narrow your view:

- **Search bar** -- Search by title, URL, or content.
- **All Statuses** -- Filter by Failed, Active, Inactive, Processing, Pending, or Pending Approval.
- **All Types** -- Filter by Web Page, PDF, DOCX, DOC, HTML, TXT, or MD.
- **All Labels** -- Filter by label tags.

Your search, filters, and page are kept in the page URL, so you can share or bookmark a filtered view.

### Viewing a Source

Click a source to open the **Source Detail** panel. It has three tabs:

- **Content** -- The text Revve extracted from the source, as the AI sees it.
- **Chunks** -- How the content was split for search.
- **History** -- The source's indexing history.

From the panel you can also change the source's expiry date. The panel's link includes the source, so you can share it with a teammate.

### Activating and Deactivating Sources

Click **Deactivate** next to any source to temporarily remove it from your agent's knowledge without deleting it. If the source is used by a chat agent, you'll be asked to confirm. Click **Activate** to make it available again.

### Re-indexing Sources

Click **Re-index** next to a source to fetch and process it again, for example after the web page or document has changed. If indexing failed, click **Retry indexing**.

### Bulk Actions

Select sources with the checkboxes to **Deactivate**, **Activate**, or **Re-index** them all at once. To act on every source that matches your filters, choose **Select all *N* matching items**.

### Pending Approval

If you have enabled the "Require approval before indexing" option on a crawler, newly discovered pages will appear under the **Pending Approval** tab. You can review and approve them before they become available to your agents.

Sources past their expiry date appear under the **Expired** tab. See [Source Expiry](/knowledge-base/source-expiry).

## Website Crawlers

For websites with many pages, manually adding each URL is impractical. Website crawlers automatically discover and index pages across an entire domain.

### Viewing Crawlers

Navigate to **Knowledge > Crawlers** in the left sidebar to see all configured crawlers.

![The Website Crawlers page showing a configured crawler with its URL, type, schedule, and run history](/screenshots/knowledge-crawlers.png)

Each crawler shows:

| Column | Description |
|---|---|
| **Name** | A descriptive name for the crawler. |
| **URL** | The starting URL for the crawl. |
| **Type** | `Crawl` for full-site crawling, or `Scrape` for a single page. |
| **Schedule** | How often the crawler runs (Daily, Weekly, etc.). |
| **Last Run** | When the crawler last ran. |
| **Next Run** | When the next scheduled run will occur. |

### Creating a New Crawler

Click the **New Crawler** button. Setup has five steps: **URL & Type**, **Scraping Options**, **Chunking**, **Schedule**, and **Review**. Click **Next** to move between steps and submit on the Review step.

The main settings are:

![Crawler configuration showing name, source URL, indexing type, approval settings, and labels](/screenshots/knowledge-crawler-config.png)

| Setting | Description |
|---|---|
| **Name** | Give your crawler a descriptive name (e.g., "Company Website"). |
| **Source URL** | The root URL to start crawling from (e.g., `https://yourcompany.com`). |
| **Indexing Type** | Choose **Single Page (Scrape)** to index only the specified URL, or **Full Site (Crawl)** to discover and index all linked pages. |
| **Require approval before indexing** | When enabled, newly discovered pages must be manually approved before they are added to the knowledge base. This is useful for large sites where you want to control which pages your agent uses. |
| **Labels** | Assign labels that will be automatically applied to all pages discovered by this crawler. |

### Crawler Schedules

Crawlers have two independent schedules:

![Crawler schedule settings showing Discovery Schedule and Content Update Schedule](/screenshots/knowledge-crawler-schedule.png)

**Discovery Schedule** -- Controls how often the crawler looks for new pages on the website. Set this to a slower pace (e.g., Daily or Weekly) since new pages are typically added infrequently.

**Content Update Schedule** -- Controls how often existing pages are re-crawled to check for content changes. Set this to a faster pace if your website content changes frequently and you need your agent to always have the latest information.

Both schedules can be toggled on or off independently, and each supports **Daily** or **Weekly** frequency.

### Crawler Tabs

Each crawler has additional tabs for deeper management:

| Tab | Description |
|---|---|
| **Overview** | Summary of the crawler's status and recent activity. |
| **Pages** | List of all pages that have been indexed by this crawler. |
| **Discovered URLs** | URLs found during crawling that have not yet been indexed. |
| **Configuration** | Edit the crawler's settings, options, and schedule. |

## Best Practices

- **Use crawlers for websites, manual uploads for documents.** Crawlers are designed for web content. Use the Upload Document option for PDFs, Word files, and other non-web content.
- **Enable approval for large sites.** If your website has hundreds of pages, enable the approval requirement so you can review which pages get indexed.
- **Set up content update schedules.** If your website changes frequently (e.g., a help center with regular updates), configure the Content Update Schedule to re-crawl weekly or daily.
- **Label your sources.** Labels help you organize content by topic, product, or department, making it easier to manage which agents use which content.
- **Check the Last Index date.** If a source has not been re-indexed recently, the agent may be using outdated information. Click **Re-index** on the source or adjust the crawler schedule.
